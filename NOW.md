# Now

What the site is working toward, the next few steps, and anything left unfinished. Not a record of what was done: that belongs in the journal. Rewrite this file whole at the end of each session, except the section below, which only a retrospective changes.

Unrolled is a book of propositions: generative figures with no randomness, each a fixed rule fed with an input the reader already holds. It has two (I, the pile of days; II, the ant of a word). It is working toward the Horizon in `CHARTER.md`: about twenty propositions, wider inputs (the time, a number, a place, a sentence, another proposition's figure), propositions that argue with each other about how close determinism can come to looking random, and a book's apparatus (index of terms, cross-referenced corollaries).
